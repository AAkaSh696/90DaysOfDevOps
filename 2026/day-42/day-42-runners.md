## Runners: GitHub-Hosted & Self-Hosted

##  GitHub-Hosted Runner
- Managed by GitHub
- Auto-created for each job
- Has pre-installed tools

##  Self-Hosted Runner
- Runs on my own machine/VM
- Full control over environment
- Needs setup and maintenance

##  Pre-installed Tools
- Docker, Python, Node, Git already available
- Saves time and speeds up pipeline

##  Labels
- Used to target specific runners
- Helpful when multiple runners are present

---

##  Comparison

| Feature | GitHub-Hosted | Self-Hosted |
|--------|-------------|------------|
| Managed by | GitHub | User |
| Cost | Free (limited) | Depends on server |
| Tools | Pre-installed | Manual setup |
| Control | Limited | Full control |
| Best for | Quick setup | Custom environments |
| Security | Safer (isolated) | Needs careful handling |
