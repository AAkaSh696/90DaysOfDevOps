## Pipeline Architecture
- Pull Request →
    - Build & Test (Reusable Workflow) →
    - PR Checks ✅

- Merge to Main →
    - Build & Test →
    - Docker Build & Push →
    - Deploy to Production 🚀

- Scheduled (Every 12 Hours) →
    - Pull Docker Image →
    - Run Container →
    - Health Check 🔍
